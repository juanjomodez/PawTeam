Semana 8

Graybox del Core Loop

Durante esta semana trabajamos en la construcción del primer graybox del Core Loop de Paw Team.

¿Qué queríamos probar?

El objetivo de esta semana fue construir el primer graybox jugable de nuestro Core Loop y comprobar que las principales acciones de Paw Team funcionaran dentro de una misma experiencia. Partíamos con una ventaja, ya que contábamos con los dos personajes principales, Lupe y Spike, junto con sus animaciones. Esto nos permitió enfocarnos en integrar sus movimientos, el mapa y las mecánicas principales para crear una primera versión jugable.

03

Cooperativo

Para la parte cooperativa ya contábamos con un botón que, al ser presionado, eliminaba un cubo de cristal que protegía un saltarín. A partir de este elemento, agregamos un nuevo botón que, al pararse sobre él, hace que unas plataformas salgan para permitir el paso del jugador.

El botón debe mantenerse presionado para que las plataformas permanezcan activas. Si el jugador se baja, las plataformas vuelven a su posición original. De esta forma, buscamos que los jugadores necesiten trabajar juntos para superar los obstáculos.

Por ejemplo, uno de los jugadores debe mantenerse sobre el botón para que el otro pueda avanzar por las plataformas. Una vez que logra avanzar, puede activar el segundo botón para eliminar el cubo de cristal y permitir que ambos continúen.
