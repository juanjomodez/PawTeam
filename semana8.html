Semana 8

Graybox del Core Loop

Durante esta semana trabajamos en la construcción del primer graybox del Core Loop de Paw Team.

¿Qué queríamos probar?

El objetivo de esta semana fue construir el primer graybox jugable de nuestro Core Loop y comprobar que las principales acciones de Paw Team funcionaran dentro de una misma experiencia. Partíamos con una ventaja, ya que contábamos con los dos personajes principales, Lupe y Spike, junto con sus animaciones. Esto nos permitió enfocarnos en integrar sus movimientos, el mapa y las mecánicas principales para crear una primera versión jugable.

01

Lumens

Los Lumens son la moneda principal de Paw Team. Los jugadores pueden encontrarlos mientras recorren el mapa y sirven para comprar objetos, conseguir mejoras o pagar algunas acciones dentro del juego, como recuperar la vida del personaje después de ser derrotado.

Para implementarlos, creamos un objeto provisional que funciona como Lumen dentro del mapa. A este objeto le agregamos un Collider, un Rigidbody y el script LumenRecolectable. El Collider permite detectar cuando uno de los personajes toca el Lumen y el Rigidbody ayuda a que Unity pueda reconocer esta interacción. Cuando Lupe o Spike lo tocan, el programa revisa que el objeto tenga la etiqueta Player. Si reconoce que es uno de los jugadores, suma un Lumen al contador y elimina el objeto del escenario para evitar que pueda recogerse otra vez.

El contador funciona con otro script llamado LumensContador. Este guarda la cantidad de Lumens que ha recogido el equipo y actualiza el número que aparece en pantalla. Por ejemplo, si el jugador tiene x5 y recoge otro Lumen, el contador cambia a x6.

02

Mapa

Para crear el minimapa utilizamos una segunda cámara, independiente de la cámara principal del juego, configurada en modo Ortográfico y ubicada sobre el personaje con una rotación en X de 90°. Esta cámara permite mostrar el mundo desde una vista superior en tiempo real.

En lugar de mostrar esta cámara directamente en pantalla, hicimos que renderizara su vista en una Render Texture. Luego, esta textura se muestra en el HUD mediante un Raw Image ubicado en una de las esquinas de la pantalla, permitiendo visualizar el entorno sin tener que crear un mapa manualmente.

Para mantener la vista actualizada, creamos el script MinimapFollow, encargado de hacer que la cámara siga constantemente al jugador. El script actualiza su posición en cada frame utilizando un offset de altura para mantener la cámara sobre el personaje.

03

Cooperativo

Para la parte cooperativa ya contábamos con un botón que, al ser presionado, eliminaba un cubo de cristal que protegía un saltarín. A partir de este elemento, agregamos un nuevo botón que, al pararse sobre él, hace que unas plataformas salgan para permitir el paso del jugador.

El botón debe mantenerse presionado para que las plataformas permanezcan activas. Si el jugador se baja, las plataformas vuelven a su posición original. De esta forma, buscamos que los jugadores necesiten trabajar juntos para superar los obstáculos.

Por ejemplo, uno de los jugadores debe mantenerse sobre el botón para que el otro pueda avanzar por las plataformas. Una vez que logra avanzar, puede activar el segundo botón para eliminar el cubo de cristal y permitir que ambos continúen.

04

Resultado final

Finalmente reunimos los elementos trabajados durante la semana para probar el Core Loop en conjunto.

¿Qué observamos o descubrimos?

Durante las pruebas observamos que algunas mecánicas todavía necesitan ajustes para funcionar correctamente. El sistema de combate presentó problemas en su funcionamiento y las mecánicas cooperativas necesitan una mejor planificación para que sean retadoras, pero también intuitivas para los jugadores.

También descubrimos que la organización del escenario influye bastante en la experiencia, por lo que algunos elementos deben distribuirse de una manera más clara. En general, las pruebas nos permitieron identificar estos problemas y entender qué aspectos debemos seguir trabajando, teniendo en cuenta que el juego todavía se encuentra en una etapa temprana de desarrollo.

¿Qué cambiaremos en la siguiente versión?

  • Modificaremos el diseño de las Lumens para que se vean de manera más estética.
  • Crearemos el mapa para el primer nivel con obstáculos y assets para decorarlo.
  • Se modificará el funcionamiento del mapa para que se actualice a medida que el jugador avance.
